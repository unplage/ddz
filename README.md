# 像素斗地主 🃏

纯前端单页斗地主 PWA，支持单机 AI 与 P2P 联机双模式。

## 快速开始

直接浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 功能特性

- **单机模式** — 对抗 AI 对手，五级难度（简单 / 中等 / 大师级 / 宗师级 / 传奇级）
- **联机模式** — PeerJS P2P 联机，房主创建房间，两人输入房间码加入
- **AI 引擎** — 增强大师级 AI，含 DP 手牌分解、MCTS 蒙特卡洛搜索、残局极小化搜索、两轮预测
- **记牌器** — 跟踪剩余牌分布、炸弹可能性、对手手牌推测
- **牌型识别** — 全牌型：单张、对子、三带一/对、顺子(5+)、连对(3+)、四带二、炸弹、王炸
- **语音播报** — Web Speech API 中文语音（单机 / 联机双模式）
- **音效** — Web Audio API 合成，无需音频文件
- **PWA 离线缓存** — Service Worker 自动缓存，断网可玩
- **战绩持久化** — localStorage 存储金币、胜负统计、历史记录
- **像素风格 UI** — Press Start 2P 字体，复古扫描线效果，触屏优化
- **AI 自学习** — 每局自动记录全部决策数据，赛后确定性复盘，检测过杀/高带牌/错误过牌
- **纠错规则引擎** — 从历史对局自动提取可推广的规则，置信度管理，实时指导出牌决策
- **CEM 参数优化** — Cross-Entropy 算法微调 AI 全部 ~40 个参数权重（参数/启发式值/阈值）
- **参数导入导出** — JSON 格式导出 AI 参数与规则，跨设备同步至 PWA
- **对局记录** — IndexedDB 持久化，含完整手牌、每步 AI 推理、复盘分析

## 项目结构

| 文件 | 说明 |
|------|------|
| `index.html` | 完整应用（HTML + CSS + UI/联机逻辑） |
| `ai_core.js` | **共享 AI 内核**：牌型/记牌器/评分/DP/残局求解/MCTS，浏览器与 Worker 双端复用 |
| `ai_worker.js` | Web Worker：`importScripts('ai_core.js')`，仅保留参数/纠错规则注入与消息处理 |
| `ai_learner.js` | AI 自学习、参数优化、复盘分析、纠错规则引擎、自我对弈验证 |
| `sw.js` | Service Worker，离线缓存 |
| `manifest.json` | PWA 清单 |
| `bench/` | Node 自对弈基准（配对测评 / 求解器探针 / 冒烟测试，不参与部署） |

无构建工具、无包管理器、无模块系统。纯内联 HTML+CSS+JS，零框架。

> `ai_core.js` 必须在 `ai_learner.js` 之前加载（`index.html` 中已保证顺序）。

## 难度差异

| 难度 | 随机性 | 残局精确解 | MCTS | 前瞻模拟 | 思考上限 |
|------|--------|-----------|------|---------|---------|
| 简单 | 0.60 | 手牌≤7 | 无 | 无 | 2s |
| 中等 | 0.30 | 手牌≤9 | 无 | 无 | 2s |
| 大师级 | 0.10 | 手牌≤15 | 600 次 / 1.2s | 1 层 | 3s |
| 宗师级 | 0.05 | 手牌≤17 | 5000 次 / 2.5s | 1 层 | 4s |
| 传奇级 | 0.00 | 手牌≤17 | 20000 次 / 4s | 2 层 | 5s |

MCTS 采用根/分支剪枝（根保留 top-12、内部 top-8，炸弹/王炸/一手清始终保留），使更多迭代集中在高价值走法上。

## AI 能力

大师级 AI 包含以下增强：

| 模块 | 能力 |
|------|------|
| DP 手牌分解 | Bitmask DP 枚举最优出牌组合 |
| 残局求解 | god-view alpha-beta 精确解（总牌 ≤20），支持过牌、置换表（点数多重集键）、时间/节点预算 |
| MCTS | 时间预算内迭代，根/分支剪枝，鲁棒子节点（胜率）选取，支持过牌 |
| 两轮预测 | 采样对手大/中/小应对，2 层深度评估 |
| 记牌器 | 剩余牌追踪、炸弹/王炸概率推测 |
| 情境炸弹 | 对手快赢时积极用炸，盲目炸受罚 |
| 增强先手 | 一手清检测、两手清规划、拆牌策略 |
| 叫分优化 | 位置权重、炸弹加成、散牌惩罚、阈值调优 |
| 赛后复盘 | 确定性重推每步决策，标记过杀/高带牌/误过牌，判断最优打法是否能赢 |
| 自我对弈验证 | 参数更新前用配对自对弈 A/B 门禁，劣于当前则拒绝，避免坏参数污染 |
| 参数同步 | JSON 导出/导入，跨设备共享优化后的 AI 参数 |
| IndexedDB | 存储无限量对局记录（含完整卡牌对象与推理快照） |

## AI 学习系统

顶部状态栏 `🤖 AI` 按钮打开管理面板，三标签页：

- **参数** — 查看/导出/导入 AI 配置，恢复默认，启动深度优化
- **记录** — 浏览历史对局，点开查看每步复盘分析（含失误标记与最优方案对比）
- **规则** — 查看自动生成的纠错规则及置信度，手动清理

### 学习流程

```
每局结束 → GameRecorder 存完整数据 → GameAnalyzer 异步复盘
  → 检测过杀/高带牌/误过牌 → 生成分析报告
  → GodViewLearner 反事实分析：用精确解/rollout 求每步最优胜率，提取特征差
  → 归一化权重更新（按特征量纲缩放）→ 自我对弈 A/B 验证
  → 胜率不劣于当前才持久化，否则拒绝（记录 accepted/rejected）
```

### 跨设备同步

在同一网络内的另一设备打开 PWA → 🤖 AI → 参数 → 导出 JSON → 导入即可同步 AI 参数与纠错规则。

## 联机模式

- 房主（Host）持有权威状态，客户端通过状态同步
- 断线自动 AI 托管（easy 难度），客户端自动重连（最多 6 次，基于持久 sessionId 恢复原座位）
- 叫分/出牌倒计时一致（叫分 10 秒，出牌 15 秒），超时自动弃权
- 「要不起」自动过牌（可在快捷栏开关）
- 快捷发言/表情（房主转发）
- 连接保活心跳 + 发送失败剔除，调试状态条实时显示

## 技术要点

- 牌值编码：3→0, 4→1, ..., A→11, 2→12, 小王→13, 大王→14
- 花色：♠♥♣♦ + JOKER
- 数据持久化：`localStorage` key `landlord_stats`（战绩）+ `landlord_ai_params`（AI 参数）+ `landlord_correction_rules`（纠错规则）
- Service Worker 自动确定作用域，支持 GitHub Pages 多项目部署
- 触摸优化：禁用双击缩放、阻止非手牌区域滚动
